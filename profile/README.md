# 71.zone

**71.zone** là studio phần mềm online-first tại TP.HCM / Sài Gòn, phục vụ doanh nghiệp vừa và nhỏ và các cửa hàng.

*71.zone is an online-first software studio based in Ho Chi Minh City, Vietnam, building websites, web/mobile applications, and practical AI tools.*

---

### Dịch vụ / What we build

Danh mục dịch vụ theo tiêu chuẩn thực tế của 71.zone. *What we offer:*

- **Website doanh nghiệp & landing page / Business websites and landing pages**: Thiết kế theo nhận diện, tải nhanh, tối ưu trên điện thoại (một trang từ 500.000đ). *Built to match your brand, fast, and tuned for phones (a single page from 500,000 VND).*
- **Web app & công cụ nội bộ / Web apps and internal tools**: Ứng dụng web quản lý đơn hàng, bán hàng, khách hàng, số hoá dữ liệu vận hành. *Web apps for orders, sales and customers, and digitizing operating data.*
- **Ứng dụng di động / Mobile apps**: App cho iPhone và Android trong cùng một dự án. *iPhone and Android apps in one project.*
- **Phần mềm theo yêu cầu / Custom software**: Xây dựng theo quy trình riêng của từng đơn vị, chuyển đổi biểu mẫu và bảng tính Excel thành phần mềm. *Built around each business's own process, turning forms and Excel sheets into software.*
- **AI ứng dụng thực tế / Practical AI**: Chatbot phản hồi tự động, AI hỗ trợ trên website, AI đọc hoá đơn và dữ liệu chứng từ. *Auto-reply chatbots, AI help on your website, AI that reads invoices and documents.*

### Công cụ / Tools

Công cụ do 71.zone phát triển, mã nguồn công khai trên GitHub. *Tools built by 71.zone, code public on GitHub:*

- [Ladilala](https://github.com/71zone/ladilala): Ứng dụng Windows gồm trình quản lý hồ sơ trình duyệt (mỗi hồ sơ có fingerprint, proxy và nhân trình duyệt riêng) và công cụ ghi, phát macro web tự điền biểu mẫu từ dữ liệu CSV, Excel, JSON hoặc REST. Có trình quản lý cập nhật. Giao diện mặc định tiếng Việt, có tiếng Anh. Phiên bản 1.1.1 ra ngày 19/11/2026. *A Windows app with a browser profile manager (each profile has its own fingerprint, proxy and browser engine) and a web macro recorder and player that fills forms from CSV, Excel, JSON or REST data. Includes an update manager. UI is Vietnamese by default, with English. Version 1.1.1 released 2026-11-19.*
- [wabgpt](https://github.com/71zone/wabgpt): Cầu nối tự host đưa tin nhắn WhatsApp của các liên hệ được chọn tới ChatGPT và gửi câu trả lời về. Có cài đặt hướng dẫn, dự án riêng cho từng liên hệ, bảng điều khiển trên terminal và web. *A self-hosted bridge that forwards selected contacts' WhatsApp messages to ChatGPT and sends the replies back. Guided setup, per-contact projects, terminal and web dashboards.*
- [agent-poisoner](https://github.com/71zone/agent-poisoner): Bộ công cụ làm nhiễu mã sau khi build để các agent LLM khó đọc: tên định danh lấy từ bộ từ vựng đối kháng, số thành biểu thức, câu thành tên hàm và comment. Có lõi dùng chung và adapter cho Vite. *Tooling that poisons build output so LLM agents struggle to read it: identifiers from an adversarial vocabulary, numbers as expressions, sentences as function names and comments. Shared core plus a Vite adapter.*
