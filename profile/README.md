# 71.zone

**71.zone** là studio phần mềm online-first tại TP.HCM / Sài Gòn, phục vụ doanh nghiệp vừa và nhỏ và các cửa hàng.

*71.zone is an online-first software studio based in Ho Chi Minh City, Vietnam, building websites, web/mobile applications, and practical AI tools.*

---

### Dịch vụ / What we build

Danh mục dịch vụ theo tiêu chuẩn thực tế của 71.zone:

- **Website doanh nghiệp & landing page**: Thiết kế theo nhận diện, tải nhanh, tối ưu trên điện thoại (từ 500.000đ).
- **Web app & công cụ nội bộ**: Ứng dụng web quản lý đơn hàng, bán hàng, khách hàng, số hoá dữ liệu vận hành.
- **Ứng dụng di động**: App cho iPhone và Android trong cùng một dự án.
- **Phần mềm theo yêu cầu**: Xây dựng theo quy trình riêng của từng đơn vị, chuyển đổi biểu mẫu và bảng tính Excel thành phần mềm.
- **AI ứng dụng thực tế**: Chatbot phản hồi tự động, AI hỗ trợ trên website, AI đọc hoá đơn và dữ liệu chứng từ.

### Công cụ mã nguồn mở / Open Source

Các công cụ và thư viện mã nguồn mở phát triển bởi 71.zone:

- [hemcss](https://github.com/71zone/hemcss): Thư viện CSS components ngữ nghĩa, OKLCH tokens, cascade layers, không phụ thuộc Tailwind ([demo](https://71zone.github.io/hemcss/)).
- [envpush](https://github.com/71zone/envpush): CLI và server tự host quản lý biến môi trường (`.env`) bảo mật cho nhóm nhỏ.
- [rundev](https://github.com/71zone/rundev): CLI khởi chạy dev server thông minh và tự động chuyển đổi file cấu hình môi trường.
- [ccm](https://github.com/71zone/ccm): CLI quản lý Claude Code agents, skills, commands và cấu hình MCP từ nhiều Git repo.
